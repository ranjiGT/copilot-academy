# Copilot Academy

An independent, community-built learning hub for GitHub Copilot concepts and GH-300 preparation. Learn with concise topic guides, original practice questions, flashcards, and local progress tracking.

Copilot Academy is not affiliated with, endorsed by, or sponsored by GitHub or Microsoft.

## Run locally

Requires Node.js 20.19+ or 22.12+.

```sh
npm install
npm run dev
```

Create a production build with `npm run build`. The generated site is static and can be hosted on GitHub Pages or another static host. The included GitHub Actions workflow deploys pushes to `main`; enable **Settings → Pages → Build and deployment → GitHub Actions** in the repository to publish it.

## What's here

- Six study areas aligned to the published GH-300 objective domains.
- Eighteen short learning topics with completion tracking.
- Original practice questions with answer explanations.
- A flashcard review set.
- Browser-local progress; no account or backend required.

The current content is an initial learning set, not an exhaustive course. Verify product behavior against the linked, current GitHub documentation.
